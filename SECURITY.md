# Security policy

## Supported versions

Only the latest release gets security fixes. The portable zip and the `.deb` do not update themselves; download the new one from the [latest release](https://github.com/Zaious/basesmall/releases/latest).

## Reporting a vulnerability

Use GitHub's private reporting: the **Security** tab, then **Report a vulnerability**. It needs a GitHub account. Please do not open a public issue.

I am the only maintainer, and I do not promise a fix date.

## In scope

- Update signature checking and the update path.
- The release files: the Windows installer and portable zip, and the macOS and Linux builds.

## Out of scope

- Errors or outages of the MLB Stats API.
- The Windows SmartScreen warning for an unsigned build (documented in the README).
