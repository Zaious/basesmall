Basesmall: Baseball, but small.
Portable version for Windows: nothing to install, no administrator rights needed.

1. Unzip this folder anywhere you can write to (Desktop, Documents, a USB stick).
2. Run Basesmall.exe.

If Windows says "Windows protected your PC": the app is not code-signed yet.
Click "More info", then "Run anyway". If the file came from the internet you can also
right-click Basesmall.exe, choose Properties, and tick "Unblock" first.

Needs the Microsoft Edge WebView2 Runtime. Windows 11 has it; most Windows 10 PCs
get it with Edge. If Basesmall does not start, that is the usual reason.

Settings are kept in %APPDATA%\io.github.zaious.basesmall\, and the web view's cache in
%LOCALAPPDATA%\io.github.zaious.basesmall\. Delete those two folders and this one to remove
every trace.

Basesmall only talks to statsapi.mlb.com (game data) and, once at start-up (you can switch
it off in Settings), api.github.com (to tell you about a newer version). It collects nothing.
This portable copy never updates itself: for a new version, download the new zip.
