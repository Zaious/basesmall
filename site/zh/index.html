主隊的比賽，放在螢幕的一個角落。

一個永遠在最上層的小視窗，用幾顆隊色棋子跟 MLB 比賽。免費、開源。

下載 原始碼

螢幕能分多少，就給它多少。

拉右下角，它就顯示多一點或少一點。

點
一顆小膠囊：比分、局數、壘包、出局數。
條
再加上球數和最新一球或打席的結果。
場
隊色棋子和壘上跑者的名字、擊球的飛行方向、好球帶裡每一球都有編號。
全
再加上投打對決和逐局比分。

瞄一眼就夠。

  • 自己跟主隊。有比賽就跟直播，沒比賽就倒數下一場，附上預告先發。
  • 一鍵藏起來。Ctrl+Alt+Shift+B 收起所有視窗；低調模式只剩一排數字，看起來不像在看球。
  • 通知不搶焦點。只跳你選的事件，卡片在角落，你打字不會被打斷。音效預設關閉。
  • 今天每一場。計分板抽屜、季後賽系列賽標示，另一場比賽後段膠著時會出現一個安靜的頁籤。
  • 重播不爆雷。2023 年以後的比賽，保留每個打席的節奏；選場時不顯示比分。
  • 你的樣子。平面或 2.5D，實底或透明。每個風格都是一個檔案，可以自己寫。

Windows

安裝版不需要系統管理員權限；公司電腦不能裝程式的話，用免安裝的 zip。

macOS

Intel 和 Apple Silicon 共用一個下載檔，已通過 Apple 簽章與公證。比 Windows 版新。

Linux

AppImage 或 .deb。自動建置，還沒在實機上試過。

程式還沒有程式碼簽章，Windows 可能會顯示「Windows 已保護您的電腦」：按「其他資訊」，再按「仍要執行」。需要 WebView2 Runtime，Windows 11 已內建。

全部在你自己的電腦上跑。

不用帳號、沒有伺服器、沒有廣告、不做分析。比賽資料由你的電腦直接向 MLB 公開的 Stats API 取得；打開設定時，會向 GitHub 問一次有沒有新版本。
